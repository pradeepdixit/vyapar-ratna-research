
## Prediction active/inactive timing

- [x] Active RuleCard अब पुस्तक अवधि के साथ active time, last matching time और inactive boundary दिखाता है।
- [x] Time-range analysis में हर event के लिए वास्तविक first matching sample से last matching sample तक का local समय दिखता है; inactive का अर्थ अगली minute/sample पर condition टूटना है।
- [x] SBC 2/24-hour windows में active अवधि, आखिरी matching sample और inactive सीमा का स्पष्ट note जोड़ा गया है।
- [x] जहाँ exact end-time उपलब्ध नहीं है, UI अनुमानित समय नहीं बनाता; “अगली गणना/sample में जाँच” स्पष्ट बताता है।
